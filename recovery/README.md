# Emberstates Recovery Index

## Contents

`Emberstates_Master_Recovery_Index.xlsx` contains six worksheets:

1. Dashboard
2. Artifact Registry
3. Links & Identifiers
4. Data Catalog
5. Recovery Queue
6. Sources & Notes

## Current evidence base

This rebuild is grounded in the surviving recovery summaries available in the associated ChatGPT project session. Those summaries report 18 indexed artifacts, seven named artifacts, seven preserved link or identifier slots, and seven archive families.

Named material presently preserved includes:

- Lantern Loadout
- Lanternworks
- Lantern-Null
- Threshold Atlas
- Civic Personhood Forge
- Cedar Finch
- Hells Branch material

## Known gaps

Exact Drive and Notion URLs, attachment identifiers, historical ZIP paths and binaries, manifests, schemas, entity lists, location lists, and several artifact names were not present in the available summaries. They are marked unresolved rather than reconstructed.

## Provenance policy

- Preserve source wording and classifications.
- Distinguish core Emberstates, Emberstates-related, and connected external material.
- Do not silently merge conflicting versions.
- Do not label material canonical without supporting evidence.
