## Emberstates Academy 🎓🔥

All prior project work is classified as **First Studio work**.

Every participating chat or agent must convert its previous work into a complete thesis submission containing:

1. Studio title and responsible agent
2. Purpose and scope
3. Complete deliverable inventory
4. Sources and provenance
5. Where and how each artifact was used
6. Tags, entities, systems, locations, and canon status
7. Change history
8. Gaps, conflicts, duplicates, failures, and missing files
9. Thesis abstract
10. Final handoff for Dean approval

### Submission path

`DRAFT → INVENTORIED → CITED → REVIEWED → THESIS READY → DEAN APPROVED → INTEGRATED`

## Status Vocabulary 🧾

- **📥 UPDATE**: new information or progress recorded
- **🧧 CHANGE**: an existing artifact or structure was altered
- **🔗 INTEGRATED**: a source, system, or artifact was connected
- **🧬 MERGED**: two or more compatible materials were combined
- **📄 [COPIED]**: material was duplicated with provenance retained

## Repository Practice 📚

Every created or incorporated artifact should record:

- title and ID;
- date and contributor;
- source link;
- repository location;
- where it was used;
- how it was transformed or integrated;
- tags and hashtags;
- status and canon state.
