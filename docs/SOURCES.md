## Source-link rules

1. Prefer a stable, direct URL to the actual source item.
2. A project, folder, workbook, filename, tag, or attachment ID is a lead until its contents are readable.
3. Preserve source title, platform, creator/account, capture date, and original URL when importing material.
4. Mark links as `live`, `historical`, `missing`, `blocked`, or `needs recovery`.
5. Do not promote visual summaries, generated dossiers, or extraction metadata into canon without explicit approval and source readback.
6. ChatGPT sandbox paths and conversation-local file citations are session-bound. Record them as provenance notes, not public links.
