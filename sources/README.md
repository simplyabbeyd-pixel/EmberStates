## Evidence rules

- A source link proves where material was reported, not that every reported item is canonical.
- Historical sandbox paths and ZIP filenames do not recreate missing binary files.
- Missing exact URLs, IDs, manifests, and archive contents remain unresolved until directly recovered.
- Conflicting versions stay separate until compared and approved.
