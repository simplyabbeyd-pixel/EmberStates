# Emberstates Project Spreadsheet Summary

## Source type

Preserved project/file-library summary.

## Supported claims

The source reports a six-sheet recovery workbook containing:

- Dashboard
- Artifact Registry with 18 recovered records
- Links, including project URLs, Drive folders, Notion pages, attachment IDs, and historical ZIP paths
- Data Catalog covering frameworks, entities, locations, systems, and asset classes
- Recovery Queue for missing archives and blocked files
- Sources & Notes with provenance and completeness rules

It also reports:

- 3 known live URLs
- 7 preserved link or attachment identifiers
- 10 high-priority artifacts
- 7 archive families

## Limitation

Historical ChatGPT sandbox ZIPs are session-bound. Filenames and paths alone do not recover the binary archives. Missing files must remain marked missing rather than reconstructed from memory.
