# Emberstates Recovery Workbook Summary

## Source type

Preserved workbook-delivery summary.

## Supported workbook structure

The source describes six organized sheets:

- **Dashboard**: recovery totals, grounded evidence, limitations, and starting actions
- **Artifact Registry**: 18 archives, spreadsheets, documents, images, attachment IDs, formats, counts, and recovery states
- **Links**: Emberstates project, confirmed Drive folder, Notion page, historical ZIP paths, and attachment identifiers
- **Data Catalog**: frameworks, NPCs, locations, objects, roles, schemas, JanitorAI assets, RAG material, and crosswalks
- **Recovery Queue**: editable status and priority fields
- **Sources & Notes**: provenance and the no-fabrication completeness rule

## Status vocabulary

The workbook distinguishes:

- live
- historically referenced
- missing
- blocked
- needs recovery

## Limitation

A prior File Library index served as the recovery skeleton. The summary supports the workbook's intended structure and classifications, but missing source files and exact identifiers still require direct recovery.
