# EmberStates

This repository is the recovery and organization hub for the **Emberstates** worldbuilding project.

## Recovery package

- `recovery/Emberstates_Master_Recovery_Index.xlsx` — six-sheet source and recovery index
- `recovery/README.md` — provenance, scope, and known limitations

## Integrity rules

- Inventory presence does not automatically establish canon.
- Missing URLs, identifiers, ZIP binaries, manifests, schemas, and entity lists remain explicitly unresolved.
- Historical ChatGPT sandbox ZIPs cannot be reconstructed from filenames alone.
- Core Emberstates material, related material, and connected external material must remain separately classified until verified.

The initial repository was empty. This README establishes the `main` branch so the recovery workbook can be committed without pretending unavailable source material was recovered.
