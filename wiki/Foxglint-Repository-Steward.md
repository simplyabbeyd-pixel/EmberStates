- **UPDATES 📥**: additions, progress, or repository status
- **CHANGES 🧧**: edits, corrections, renames, or restructuring
- **INTEGRATED**: source incorporated into a larger system
- **MERGED**: multiple sources combined while preserving provenance
- **[COPIED]**: retained material not claimed as original work
